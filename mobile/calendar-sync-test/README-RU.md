# Path на компьютере и телефоне

Это локальная тестовая сборка для одной общей базы. Сервер запускается на компьютере. Устройства обмениваются данными по HTTPS, пока Path открыт. Для проверки используйте вымышленные записи. Доступ к базе имеет любой клиент с доступом к этому порту в вашей сети. Учётных записей в этой сборке пока нет.

## Обновление

1. Остановите старый сервер сочетанием Ctrl+C. Распакуйте ZIP с заменой файлов в прежнюю папку с `Start.cmd` и `calendar-test.sqlite`. Этот файл хранит вашу базу. В архиве новой базы нет.
2. Для проверки в двух вкладках на одном ПК откройте `Start-PC.cmd`. Для iPhone и ПК запустите `Start.cmd`. Скрипт определяет адрес домашней сети. Если сетевых адресов несколько, укажите адрес нужного адаптера. Например, команда для 192.168.1.101 будет `Start.cmd 192.168.1.101`. Сертификат должен включать этот адрес. Как и в предыдущей сборке, для запуска нужны Python 3 и ранее настроенный локальный HTTPS.
3. После обновления в каждом используемом браузере откройте адрес <code>/open.html</code> из строки «Open Path» в окне сервера. Страница проверит сервер и дождётся загрузки актуальной сборки. С неё откройте компьютерную или мобильную версию. В панели «Тест обмена» появится **Path Sync 4**. Номер рядом с «Синхронизировано» относится к базе данных.
4. Дождитесь «Синхронизировано» с одинаковым номером версии. Если появляется «Открыта другая тестовая база», проверьте папку запущенного сервера. Переустановка приложения и очистка браузера для обновления не требуются.

## Что передаётся

| Вкладка | Данные |
| --- | --- |
| Today и Projects | Задачи, проекты, вложенные задачи, сроки и отметки о выполнении. |
| Calendar | События, дедлайны, важность, время, часовой пояс, серии и связанные события. |
| Habits | Правила, значения по датам и архив. Привычки с подсчётом или длительностью поддерживают ввод значения для доступного дня. |
| Sport | Программы, шаблоны, свои упражнения, избранное, планы в календаре, активная тренировка, подходы, результаты и история. Вход в каталог на телефоне находится в Sport → Exercises. |
| Notes | Обычные заметки, содержание, архив и корзина. Личный дневник остаётся на устройстве. |
| Canvas | Доски, содержимое карточек и связи передаются с ПК. На телефоне доступны просмотр, масштаб и перемещение по доске. Сложные доски открываются списком карточек и связей. |
| Progress | Итоги рассчитываются из записей о задачах, занятиях, привычках и подтверждённых периодах фокусировки. |

Масштаб и положение доски, язык, настройки движения и история отмены остаются на устройстве. Форматы, которые мобильный редактор пока не поддерживает, доступны для просмотра. Примером служат события старого формата без часового пояса.

## Быстрая проверка

На ПК создайте событие с высокой важностью и заметку. Откройте на телефоне дату события и вкладку Notes. Измените текст заметки на телефоне и проверьте его на ПК. В Sport отметьте упражнение звёздочкой и откройте избранное на другом устройстве. Создайте доску на ПК и откройте её на телефоне.

После статуса «Можно открывать без сети» оба интерфейса сохраняют изменения локально. Обмен выполняется автоматически примерно раз в пять секунд и возобновляется при подключении. Во время ввода закончите редактирование и закройте форму. Несовместимые изменения одной записи потребуют выбора в панели «Тест обмена». Для связанной тренировки, серии и её событий решение применяется к согласованному набору данных. После выбора дождитесь одинаковой версии на обоих устройствах.
