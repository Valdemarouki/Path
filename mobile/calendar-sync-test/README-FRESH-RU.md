## Новый запуск

1. Распакуйте папку Path-Sync-4-Fresh из архива в новое место, например в Загрузки.
2. Откройте Start-PC.cmd двойным щелчком и оставьте окно сервера открытым. Для запуска нужны Python 3 и настроенный на этом компьютере сертификат Path.
3. На компьютере откройте https://127.0.0.1:8444/open.html и дождитесь «Готово». Откройте ссылки на компьютерную и мобильную версии в двух вкладках.
4. Проверьте в обеих вкладках надпись Path Sync 4. Создайте событие на ПК и откройте ту же дату в мобильной вкладке.

Эта копия создаёт свою тестовую базу calendar-test.sqlite в новой папке. Браузер хранит данные порта 8444 отдельно. Для следующих запусков используйте тот же Start-PC.cmd из этой папки.

Для последующей проверки на iPhone остановите этот экземпляр сервера с помощью Ctrl+C и запустите Start.cmd из той же папки. Используйте адрес из строки Open Path в окне сервера. На телефоне потребуется доверенный сертификат для текущего IP компьютера.
