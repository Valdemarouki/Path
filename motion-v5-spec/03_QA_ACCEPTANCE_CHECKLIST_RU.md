# Motion Master v5 — перечень приёмочных проверок Astra

Отмечать выполненным только после проверки **в настоящем работающем Path**, а не автономном HTML.

## Портреты
- [ ] У 6 исходных SVG ровно 516 точек, общий viewBox, дефолт Wave **4px / 1450ms**, корректный Reset.
- [ ] Today→Sport Overview→Progress Overview→Notes intro: в каждом переходе **один** moving portrait, реальные разные якоря; нет fade-swap.
- [ ] Today→Calendar→Today: на Calendar портрет исчезает; возвращение собирается без телепортации.
- [ ] Быстрое A→B→C→A (5–20 раз подряд) не телепортирует/не оставляет второй слой и сохраняет 516 частиц.
- [ ] Resize/150% DPI/узкое окно/смена route во время wave не вызывает скачка центра, перекрытия UI или некорректного input handling.
- [ ] Ambient не масштабирует целый бюст. Импульс 4–8 соседних точек, редкий, мягкий, затем полная остановка; нет ambient при MORPHING.
- [ ] Отсутствие философа на Canvas/Projects/Calendar/Settings, отсутствие в Notes editor/Workout Mode/Progress details; Habits не получает непроверенного персонажа.
- [ ] Параметры волны сохраняются при перезапуске и миграциях; пользовательские настройки не переписываются новыми умолчаниями.
- [ ] Reduced Motion и Off — полностью без spatial wave и ambient.

## Today и completion
- [ ] Hold ~800ms на отдельном completion handle, cancel на pointercancel/scroll/ESC; mouse/keyboard имеют доступный эквивалент.
- [ ] После успешного durable commit галочка 0.28→1.32→0.89→1.055→1 за ~565ms, не до сохранения.
- [ ] Retry и неудачная запись не создают фальшивый Done/Progress, нет двойных completion событий.
- [ ] Повторный React rerender/навигация/Sync не перезапускает spring на уже завершённой задаче.
- [ ] Один локальный Path Pulse ~250–320px, без постоянных изменений layout соседних карточек.
- [ ] Habits и set completion получают только Micro Completion, без тяжелого Pulse.

## Графики
- [ ] 7 последовательных столбиков растут и уменьшаются от текущей высоты при реальном изменении хранилища; duration ~760ms, stagger ~30ms.
- [ ] Вход/выход из Today и 20 быстрых обновлений не пересоздают график с нулевых высот.
- [ ] Пустое состояние не равно «0», шкала/подписи/единицы корректны, 0/negative/large values обрабатываются безопасно.
- [ ] Progress и Today считают одинаковые события; уникальные task IDs и session records не задваиваются.
- [ ] Reduced Motion/Off исключают декоративную анимацию столбиков, но не данные.

## Навигация и общие компоненты
- [ ] Отдельная колонна, только 8 кнопок, Home temple, Profile+Settings вне неё.
- [ ] Ровно один движущийся selection indicator; нет двух активных рамок.
- [ ] Доступные hitbox >=44–48px, без перекрытия волют и основания, при 1366×768/1920×1080/125%/150% DPI.
- [ ] Hover/Press/Release/Focus/Reduced состояния консистентны и не мешают клавиатуре.
- [ ] В Calendar/Projects/Canvas drag не «запаздывает» из-за spring; drop settles once; не изменяется сохраняемое время/задача до подтверждения.
- [ ] В Sport таймеры/подходы не прыгают, в Notes нет анимации набора текста.
- [ ] Shared project: удалённая отметка задачи не запускает длинный личный Path Pulse у каждого коллеги.

## Сквозные технические и UX
- [ ] Windows build + Web build запускаются, выполнен smoke test минимум 10 минут, нет консольных ошибок.
- [ ] 60fps подтверждено замерами frame durations на целевой машине/браузере либо объяснены измеренные ограничения; нет заявления без проверки.
- [ ] Hidden browser tab и route unmount прекращают rAF/timers и не расходуют CPU в фоне.
- [ ] Режим Off/Subtle/Expressive сохраняется; системный Reduced Motion уважён.
- [ ] Focus / accessibility / aria-label / keyboard no-hold alternative.
- [ ] Локальные данные и Path 1.x/production не затронуты; проведена проверка совместимости и резервная копия.
