## Не делать
- Не изменять Path 1.x, публичный сайт, пользовательские файлы или текущие настройки без миграции.
- Не выдавать отдельный HTML-прототип за внедрение в рабочий Path.
- Не переписывать приложения и его экраны с нуля для переноса эффектов.
- Не использовать рамки Active, нарисованные внутри SVG из набора `states/`, одновременно с одной общей анимированной рамкой.
- Не встраивать в пользовательскую базу демонстрационные данные Today.
