# Аудит противоречий: новая каноническая версия v5

| Раннее предложение/файл | Последнее утверждённое правило |
|---|---|
| Wave 18px и 1250ms в v3/v4 | **Wave 4px и 1450ms**, сохранять пользовательские изменения |
| Ранее амбиентное «дыхание» всего бюста / общий scale | **Только локальные группы соседних точек**, не весь бюст |
| Морф только на месте / crossfade | Living Particle Wave **с перелётом между настоящими DOM anchors** |
| 516 SVG совпадают по ID => можно маппить по index | Неверно; **предвычисленное spatial matching** |
| Morph duration 900–1100ms в первоначальной спецификации | Последнее решение для travel wave **1450ms**; stationary morph может быть короче только по осмысленному дизайну и не при переезде между вкладками |
| Active SVG уже имеет выделенную рамку, ещё одна в общем UI | Одна shared moving frame; использовать **clean glyph icons**, state SVG только референс |
| Оригинальная колонна 71×375 вмещает 8×50px | Не вмещает; адаптировать **только центральную часть**, а не делать завитки/основание другой формы |
| Settings как шестерёнка в колонне | **Settings только в Profile** |
| Habits отрисован с Aristotle на старом макете | **Философ Habits ещё не утверждён**; Aristotle = Progress |
| Bounce на каждом изменении числа/графика или React rerender | Только при **событии** и реальном изменении; числовой текст не bounce |
| Задача автоматически Done при начале анимации | До подтверждённой durable persistence — не финальный Done |
| Новые эффекты требуют новой архитектуры приложения | Дополнять текущую, через adapter; **не переписывать** рабочие вкладки |

### Не путать прототипы с production
Демо HTML — визуальные прототипы. Их нельзя считать реализацией на Windows, Android, macOS и iOS. Astra должна перенести алгоритмы в исходники текущего Path 2.0 и доказать работу на настоящих экранах.
