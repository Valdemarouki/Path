ПОВЕДЕНИЕ
- У неактивной иконки тонкий серый outline; при Hover она светлеет с лёгким подъёмом; у Active — белая заполненная/усиленная версия.
- Рамка активной вкладки — ОДИН общий элемент поверх колонны: плавное перемещение по вертикали, мягкая пружина без резкого дёргания, около 560 мс. Не рендерить рамку внутри каждой иконки.
- Пружинность и подсветку держать деликатными, не превращать колонну в неоновую панель.
- Нажатие и переход не блокируют пользовательские действия. При быстром переключении рамка идёт из текущего положения в следующее без сброса.
- Сохранить существующие маршруты, горячие клавиши и состояние выбранной вкладки.
- На мобильных экранах использовать отдельную подходящую навигацию; не пытаться уместить 8 маленьких иконок в колонну длиной 375 px.
- При prefers-reduced-motion отключать пространственные эффекты.
- Отдельные SVG должны оставаться реальными SVG, не заменять их PNG и не использовать картинку-макет как фон кнопок.
