# Path 2.0 — Ionic Navigation SVG v2

**Что отправить Astra:** приложить весь ZIP и вставить текст из `ASTRA_READY_PROMPT_RU.md`.

Папки:
- `svg/column` — прозрачная колонна без иконок, отдельная рамка Active и статический составной пример.
- `svg/icons/idle`, `svg/icons/hover`, `svg/icons/active` — по 10 SVG: 8 страниц + Profile и Settings (последние 2 **не помещать** в колонну).
- `svg/previews` — векторные дизайн-листы, PNG как удобное превью (не исходник).
- `demo` — HTML/CSS-пример с одним передвигающимся выделением и работающими кнопками.
- `docs` — технические требования, размеры, states, ограничения и тесты.

**Последняя картинка содержала 7 значков.** В обновлённом комплекте добавлены Habits, чтобы были все 8 страниц.
Колонна повторяет утверждённое направление референса, но геометрия заново вручную создана в SVG (не пиксельная копия фотографии).
