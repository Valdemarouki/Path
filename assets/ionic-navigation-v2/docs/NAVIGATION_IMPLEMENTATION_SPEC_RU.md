# Path 2.0 · Ionic Navigation SVG v2

## 1. Статус решений
- Колонна: утверждённое новое направление по последнему референсу (прямой стержень, две ионические волюты, два прямых ребра основания). Этот пакет — аккуратная **векторная реконструкция**, а не автоматическая трассировка растра с попиксельным совпадением.
- Иконки: переработаны в едином семействе: одинаковая площадь 24×24, круглые окончания, stroke 1.55 px (Idle), 1.7 px (Hover), 1.8 px (Active). Active имеет отдельные заполненные элементы.
- Только один `Active_Focus_Frame.svg`; в файлах active-иконок рамок нет.
- Settings не является кнопкой колонны. Profile вынесен в правый верхний угол.
- Порядок соответствует последнему референсу сверху вниз: Today, Calendar, Sport, Projects, Canvas, Notes, Progress. **Habits вставлена между Canvas и Notes**, потому что это отдельная восьмая вкладка приложения.

## 2. Точные SVG
- Прозрачный фон; SVG состоит из векторных `rect`, `path`, `circle` и градиентов/фильтров (для колонны), никаких встроенных raster images.
- `svg/column/Ionic_Column_NO_ICONS.svg`: viewBox 0 0 180 1190. Капитель в верхней части, прямой стержень, основание снизу. Стержень специально удлинён для восьми элементов.
- `svg/column/Active_Focus_Frame.svg`: viewBox 0 0 96 94; рамка с округлением, лёгкое монохромное свечение, без значка.
- `svg/icons/{idle,hover,active}/NN_name.svg`: 10 иконок × 3 состояния; первые восемь в левой колонне, Profile и Settings — только во вспомогательной области.
- `svg/column/Ionic_Column_With_Icons_Example.svg` — **статическая** композиция: служит для сравнения внешнего вида, но не должна заменять интерактивную навигацию.
- `svg/previews/Icons_States_VECTOR.svg` и `svg/previews/Navigation_Full_Layout_VECTOR.svg` — полностью векторные дизайн-листы.

## 3. Компоновка (относительные координаты 180×1190)
- Центр кнопок по x=90, y=[216, 327, 438, 549, 660, 771, 882, 993].
- Вертикальный шаг 111 единиц; выделение 96×94, левый x=42, top = y_selected−47.
- Иконки встроены в квадрат 24×24; на статичном примере масштабированы в 48×48; при физической высоте колоны 750px иконка получится около 30px.
- Хит-область должна быть шире геометрии иконки. Если при реальной высоте колоны это менее ~40–44 CSS px, пересмотреть плотность/скролл/desktop breakpoint, не обрезая элементы.

## 4. Анимации
- Active frame: `560ms cubic-bezier(.18,1.15,.32,1)`, одно непрерывное перемещение; альтернативно пружинный solver с затуханием.
- Hover: 180ms, усиление яркости outline и подъём не более 1–2px.
- Press: лёгкое сжатие ~0.92–0.96, возвращение ~220–300ms.
- Анимации навигации должны сосуществовать с Living Particle Wave **4px / 1450ms**, не блокируя её.
- При переходе на вкладку без философа портрет разлетается согласно Motion Master, но сам sidebar остаётся неизменным.
- Reduced motion: мгновенная установка актуальных координат и состояния без перемещений.
- Не надо анимировать высоту всей колонны или масштабировать греческий орнамент.

## 5. Технические правила
- Использовать `button`/доступные интерактивные элементы с aria-label. Навигация работает с клавиатуры, отображает фокус и tooltip.
- Сохранять выбранную вкладку через существующий router/state, а не только менять label в демо.
- Активные SVG отдельно не содержат рамку. Не совмещать старые active-state PNG с новым focus SVG.
- Не встраивать `svg/previews` как production layout: это только демонстрация.
- Высоту колонны рассчитывать по доступной высоте с учётом 8 hit targets и безопасного отступа капители и основания. При недостаточной высоте использовать адаптивный режим, а на телефоне — отдельную нижнюю навигацию.
- Строгая монохромность, без settings иконки в колонне.

## 6. Приёмочные проверки
1. Каждая из восьми кнопок открывает существующую вкладку.
2. Видна ровно одна подсвеченная рамка на активной иконке.
3. Она перемещается без прыжков при быстром выборе разных вкладок.
4. Hover/Active/Idle читаемы при уменьшенном масштабе.
5. Настройки доступны из Profile, а не из колонки.
6. Колонна не обрезает завитки, основание или крайние кнопки на распространённых размерах окон.
7. Поддерживаются Tab, стрелки, Enter/Space, Escape для профиля и Reduced Motion.
8. Не ломаются состояния Today, Canvas, Calendar, Sport, Projects и прочих разделов.
9. Переключение и анимации не вызывают ложного сохранения, потери черновиков или резких скачков портретов.
10. Не изменяется Path 1.x или публичный продакшен.

## 7. Границы прототипа
Демонстрационная HTML-страница показывает кнопки и анимированный фокус, а не все настоящие вкладки. Astra должна интегрировать **отдельные ассеты**, а не заменять существующее приложение демонстрацией.
