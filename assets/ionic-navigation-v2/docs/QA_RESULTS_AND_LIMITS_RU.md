# QA / Path 2.0 Ionic Navigation v2

Проверки, выполненные при сборке:
- 35 файлов SVG разобраны XML-парсером без ошибок.
- Ни один SVG не содержит тег `<image>` (нет встроенного raster).
- Проверен и отрисован SVG отдельной колонны, собранного навигатора и всех состояний иконок через CairoSVG.
- 8 кнопок навигации обнаружены в HTML; соответствуют 8 существующим вкладкам.
- Profile/Settings не включены в 8 основных кнопок.
- Все относительные URL иконок/колонны в HTML указывают на реально существующие файлы.
- Встроенный JavaScript прошёл `node --check` (синтаксис).
- CSS разобран без ошибок синтаксиса.
- Опробовать HTML в Chromium через file:// и локальный HTTP не удалось: среда блокировала переходы (net::ERR_BLOCKED_BY_ADMINISTRATOR). Поэтому **интерактивное поведение необходимо отдельно проверить в Astra/браузере пользователя**; не считать его протестированным лишь по синтаксису.

Оставшиеся приёмочные действия при интеграции:
1. Реальная маршрутизация всех восьми вкладок в текущем коде.
2. Согласование позиции рамки при изменении ширины/высоты окна.
3. Проверка Hover/Active/Reduced Motion на реальных дисплеях.
4. Быстрые переключения и сохранение текущего состояния проекта.
5. Проверка читаемости и размера hit targets, клавиатуры и экранного диктора.
6. Проверка совместимости с существующим Motion Master v5 + Path Pulse v6.1.
7. Сравнение со скриншотом-референсом перед утверждением production.
