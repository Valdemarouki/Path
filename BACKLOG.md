# Очередь задач
- [x] Успешно проверен изолированный рабочий процесс Paperclip: Developer → Git commit → QA.
1. **Проверить исходную точку.** Без правок выполнить начальные команды из QA_CHECKLIST.md и записать результаты. Критерий готовности — все команды завершились успешно, рабочее дерево чистое.
2. **Воспроизвести ошибку установки.** В отдельной Windows VM со снимком и синтетическим профилем проверить обновление с RC17. Записать путь установки, состояние процессов, код выхода и подробности шага удаления. До воспроизведения причина неизвестна. Критерий исправления — повторяемый переход на новую версию с сохранением тестовых записей. Только владелец передаёт тестировщику нужные артефакты.
3. **Закрепить исправление Daily Habits.** Проверить переход с прошлой даты Calendar в Today и Habits, смену дня, ежедневное расписание и выбранные дни. Критерий — списки и счётчики совпадают для текущего системного дня, Calendar помнит свою дату.
4. **Проверить личные данные при обновлении модели.** На синтетическом наборе экспортировать, импортировать, перезапустить и сверить идентификаторы, расписания и историю отметок. Реальные пользовательские бэкапы не использовать.
