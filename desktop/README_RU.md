# Path 2.0 — Windows Preview

Это текущее приложение Path 2.0 в отдельной desktop-оболочке, без изменений Path 1.x и публичного сайта.

## Запуск предварительной сборки

Распакуйте весь архив Path-2.0-Windows-x64-Preview.zip в отдельную папку и запустите `Path 2.0.exe`. Не перемещайте EXE отдельно от остальных файлов. Это распакованная сборка, не установщик. Запуск на Windows ещё не проверен. Сборка не подписана; используется стандартная иконка Electron.

Данные хранятся в отдельном профиле `%APPDATA%/Path-Paperclip-Test`. Чтобы перенести данные из HTML-версии, сначала экспортируйте резервную копию через Settings (с Journal при необходимости), затем импортируйте её в Settings приложения. Сохраните исходный файл резервной копии. Автоматического переноса браузерного хранилища нет.

## Для разработки

`npm ci`, затем `npm start`. Проверка упаковки: `npm run prepare:app` и `npm run check`. Сборка установщика на Windows: `npm run dist:win`. Версии зависимостей закреплены в package-lock.json.

## Проверено 29.10.2026

- В интерфейсе HTML-приложения: экспорт с Journal, восстановление, отклонение неподдерживаемой версии, перезагрузка и повторный экспорт. JSON до и после полностью совпадает.
- Синтаксис desktop-оболочки, CSP-хеши двух скриптов, отсутствие inline HTML-обработчиков.
- Windows x64 PE и побайтовое совпадение main.cjs и app/index.html внутри app.asar с исходниками; совпадение name/version/main в производственном package.json.
- Установщик NSIS не завершён: в среде сборки отсутствует Wine. Промежуточный Setup.exe не распространяется.

## Осталось проверить на Windows

Первый запуск, все восемь вкладок, импорт и экспорт через системный диалог, изображения Canvas, внешние ссылки, сохранение после закрытия и повторного запуска, ошибки записи и Retry, закрытие при несохранённых данных, масштабирование окна и Reduced Motion. Затем подготовить подписанный установщик и собственную иконку.

Шрифты пока загружаются из Google Fonts; без сети используются резервные шрифты. Проверка браузерной версии не заменяет проверку desktop-приложения.

## Обновление beta.4 — тестовый установщик

Добавлены фирменные иконки из действующего SVG Path, тёмное оформление NSIS, English/Русский и план подписанного выпуска. Новые файлы и точный статус проверок: `project-control/WINDOWS_INSTALLER_QA_RU.md`, план: `project-control/WINDOWS_RELEASE_PLAN_RU.md`.

Обычная сборка на Windows: `npm ci`, `npm run dist:win`. Подписанная: настроить `PATH_SIGNING_MODE`, `PATH_SIGNING_PUBLISHER` и параметры сертификата/провайдера по плану, затем `npm run dist:signed`. Публикация отключена. Источники не содержат сертификатов и ключей.

Для ограниченной Linux-среды: сначала `npm run prepare:app`, затем `npx electron-builder --win --x64 --dir --publish never`, после — `node build-review.cjs`. Последняя команда собирает НЕПОДПИСАННЫЙ тестовый NSIS, используя штатный offline UninstallerReader из закреплённой версии electron-builder; она не запускает Windows EXE. При обновлении electron-builder адаптер требует повторного аудита. Для публичного релиза использовать обычную Windows-сборку и проверенную подпись.

Установщик устанавливает приложение для текущего пользователя; профиль `%APPDATA%/Path-Paperclip-Test` остаётся прежним. Тестовая сборка не является проверенным публичным релизом. Не отключайте защиту Windows; если система блокирует неподписанный файл, отложите запуск до подписанной сборки.
