# RC9 — автоматическая синхронизация Today / Projects

Приватная тестовая сборка Windows x64, без цифровой подписи. Серверная схема прежняя. Path 1.x, публичный сайт и публичный установщик не изменены.

## Реализовано
В Profile: «Включить автосинхронизацию» с явным подтверждением объёма данных. Разрешение сохраняется отдельно для каждого аккаунта на этом компьютере. По умолчанию выключено; после включения сохраняется при перезапуске. Гостевой профиль не синхронизируется.

Отправка сохранённых задач/проектов примерно через 2,5 секунды после изменений; проверка облачных изменений каждые 15 секунд в спокойном состоянии. Online/focus ускоряют следующую попытку. Одна операция одновременно. При ошибках задержка растёт от 5 секунд до 2 минут. При конфликте, незавершённом восстановлении, HTTP 401/403 или связанном удалении автообмен приостанавливается и требуется действие в Profile. Ручная синхронизация и выбор версии остаются доступны.

Фоновый обмен не вызывает экран загрузки, blur, принудительный flush или закрытие редакторов. Входящие изменения ожидают завершения редактирования/жеста. Перед локальным применением проверяется актуальность исходного снимка. Если пользователь начал работать во время сетевого запроса, применение откладывается без перезаписи. Изменения во время отправки не отмечаются как подтверждённые: остаются pending для следующей попытки.

Новые изменения и Undo уже сохраняются штатным PathRepository; уведомление планировщику отправляется только после успешной локальной записи Today/Projects. Canvas-only изменения не создают такое уведомление. При закрытии приложения локальные данные остаются в checkpoint; отправка продолжится после открытия. Это не отдельная служба Windows, когда Path закрыт, обмен не выполняется. Пауза прекращает следующие запуски; уже начатый запрос может завершиться.

Статусы в Profile (EN/RU/PL/ES): выключено, ожидание редактирования, изменения ожидают отправки, синхронизация, облако подтвердило данные, повтор после ошибки связи, требуется внимание. Неподтверждённые изменения не получают статус успешного сохранения.

## Изменённые файлы
- desktop/auto-sync.js — планировщик, debounce, polling, backoff, single flight и пауза конфликта.
- desktop/account-renderer.js — согласие, кнопка включения/паузы, статусы, реакция на события, связь с ручным разрешением конфликтов.
- desktop/sync-renderer.js — проверка активного ввода, условное применение без overlay, уведомления об успешных записях задач/проектов.
- desktop/sync-host.cjs — фоновый режим без flush/блокирующего экрана.
- desktop/main.cjs, preload.cjs — проверенный IPC и локальная настройка для каждого аккаунта.
- cloud-sync/session.cjs — повторное чтение локальных изменений после сетевого чтения и ACK; безопасная отсрочка pull; отсутствие повторной записи неизменившегося журнала.
- desktop/prepare.cjs, package.json, package-lock.json; сформированные desktop/app/index.html и desktop/cloud-sync/session.cjs.
- project-control/check-auto-sync.cjs; расширены check-account-host.cjs и check-account-renderer.cjs.

## Проверено
PASS планировщик: объединение частых изменений, одиночный запрос, задержки/возобновление, отключение во время запроса, ожидание редактора, пауза конфликта и отказа доступа.
PASS sync engine: правки во время read и push, новый pending после ACK, отсрочка применения и последующий pull, прежние тесты диска/сбоев/backup/Undo/конфликтов/изоляции.
PASS compiled HTML/jsdom: ввод в поле блокирует фоновое применение, pointer guard, применение без overlay, задача вызывает уведомление, Canvas-only запись не вызывает его.
PASS аккаунты/OAuth/IPC/перенос гостевого профиля. Проверены запрет включения гостем, проверка отправителя, тип аргумента и независимость настройки аккаунтов.
PASS PostgreSQL PGlite: схема/RPC/права/CAS/повторы/история. PASS диагностика конфликтов и Canvas isolation.
PASS упаковка HTML/CSP и Windows x64 NSIS. Нативный Windows UI и реальный фоновой обмен между двумя устройствами в этой среде НЕ проверены.

## Проверка на двух компьютерах
1. Установить RC9 поверх RC8 на обоих компьютерах.
2. Войти в аккаунт. Profile → «Включить автосинхронизацию» / Enable automatic sync → подтвердить на каждом компьютере.
3. Создать задачу на A; закончить редактирование. На B выйти из полей/редакторов и подождать до 20–30 секунд. Кнопку синхронизации не нажимать.
4. Изменить задачу на B и проверить получение на A.
5. На A отключить сеть, изменить тестовую задачу, закрыть/открыть приложение; восстановить сеть и проверить получение на B.
6. Проверить конфликт одновременных изменений: автообмен должен остановиться, обе версии остаться доступны. После явного выбора версии он продолжится.
7. Проверить Pause и перезапуск: выключенная настройка остаётся выключенной; включённая возобновляет работу.

## Ограничения
Только Today tasks и Projects. Canvas, Notes/Journal, Sport, Calendar, Habits, настройки и вложения не включены. Конфликты целого снимка, автоматического слияния нет. Большие активные редакторы откладывают получение. После паузы/ошибки всегда можно использовать ручной обмен.
Резервные копии перед pull сохраняются локально; автоматическая очистка старых копий пока не реализована. Перед публичным выпуском нужны лимиты хранения/истории, отдельное резервирование сервера и дополнительные нагрузочные проверки. RC9 остаётся частным тестом.
