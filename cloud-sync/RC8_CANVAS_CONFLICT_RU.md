# RC8: проверка Canvas и диагностика конфликтов

## Результат расследования
В скомпилированном приложении воспроизведены создание/редактирование обычной Canvas Note, перемещение, масштаб/viewport, создание стрелки и удаление карточки. Проекция Today/Projects осталась побайтно эквивалентна по данным, новая облачная задача получена без конфликта. Convert to Task ожидаемо изменяет Projects. Конкретная причина конфликта на компьютере друга НЕ установлена: снимков до конфликта нет. Нельзя утверждать, что виноват Canvas или что этот пользовательский случай полностью исправлен.

## Изменения
- cloud-sync/replica.cjs: устранён «застрявший» конфликт. При повторе проверяется актуальная облачная версия. Если локальная версия вернулась к общей базе либо совпала с облачной, конфликт снимается и выполняется безопасное получение. Откат серверной ревизии или изменение данных без смены ревизии по-прежнему запрещены.
- Там же: описание различий локальной и облачной версий относительно общей базы: тип записи, название, добавление/удаление/изменение, имена изменённых полей. В интерфейсе максимум 10 записей с каждой стороны. При отсутствии общей базы это явно отмечается. Обычные изменения Canvas не включаются.
- desktop/account-renderer.js: подробности конфликта выводятся как безопасный текст. Названия задач не становятся HTML. Отображение EN/RU (для PL/ES описание различий пока на английском).
- desktop/package.json и package-lock.json: 2.0.0-rc.8.
- desktop/app/index.html и desktop/cloud-sync/replica.cjs: пересобранные производные файлы.
- project-control/check-canvas-sync-isolation.cjs: регрессия на скомпилированном приложении.
- project-control/check-sync-conflict-details.cjs: сравнение полей и повторная проверка конфликтов.

## Проверки
PASS: Canvas isolation в скомпилированном HTML/jsdom; новые облачные задачи после обычных изменений Canvas; Convert to Task как настоящая правка проекта.
PASS: поля title/done в диагностике, отмена локальной правки, совпадение обеих версий, отказ откату/подмене серверной ревизии.
PASS: PostgreSQL PGlite Cloud Sync, интеграция checkpoint/очередь/сбои/Undo/backup/linked deletion, аккаунты/OAuth/host/UI/перенос гостевого профиля, проверка HTML/CSP.
Windows x64 NSIS собран без цифровой подписи. Нативная установка и интерфейс Windows в этой среде не проверялись. Изменения сервера не нужны. Публичная публикация не выполнялась.

## Как проверить вдвоём
1. Установить RC8 поверх RC7 на обоих компьютерах. Синхронизироваться последовательно до одинаковых данных без конфликта.
2. Друг меняет только обычные Canvas Note: текст, положение, стрелки. Не Convert to Task и не связанную задачу.
3. Владелец создаёт тестовую Today-задачу и синхронизирует, затем друг синхронизирует. Ожидается новая задача без конфликта.
4. Если конфликт повторится, не выбирать версию: сделать скриншот новых списков различий. Они покажут фактически изменившиеся записи/поля.

Canvas всё ещё не синхронизируется между устройствами. Автообмен выключен. Данные и гостевой профиль сохраняются; при настоящем конфликте остаётся выбор целого набора Today/Projects с резервной копией.
