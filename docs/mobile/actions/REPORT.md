# Path Mobile — общая система действий

Исходная точка: `/workspace/Path`, ветка `feature/path-mobile-alpha`, чистый HEAD `3deb48c2a36dd3ace2667fb7a8272b5763dd67a1`. Изменение касается оформления существующих действий, а не их поведения.

## Общая реализация

`mobile/actions.mjs` формирует подписанную второстепенную кнопку, главное создание с плюсом или icon button. Сохраняются исходные IDs, `data-*`, тип `button` и обработчики. SVG имеют единый stroke 1,5, круглые окончания и размер 22 px; декоративные SVG исключены из accessibility tree. Для icon buttons доступны локализованные `aria-label` и `title`.

`mobile/actions.css` задаёт единые поверхности, размеры и состояния. Creation: фон `#EEEDE9`, текст `#19191D`, радиус 16 px, Manrope 500, статичный мягкий блик `0 0 16px #ffffff12`. Ширина по содержимому, максимум 100% родителя; длинный текст переносится. Минимальная высота обычной кнопки 48 px, иконки — 48×48 px; компактные действия completion-message — минимум 44×44 px.

Второстепенные подписанные кнопки графитовые, без подчёркивания; иконки не имеют постоянного свечения. Основной текст controls — Manrope 400, главное создание — 500. В обычном motion нажатие даёт scale .97 с возвратом за 170 мс; меняются только paint-свойства кнопки, соседи не сдвигаются. При OS reduced motion или Path Motion Off масштабирование отсутствует, остаётся короткая смена поверхности. Keyboard focus: видимая светлая рамка 2 px с отступом 4 px. Disabled: штатный `disabled`, уменьшенная opacity, без свечения и нажатия.

## Trash: прежнее поведение сохранено

`toggle-trash` лишь меняет текущий список — не удаляет запись и не вызывает commit. В каждом языке тест сравнивает точную строку localStorage до и после перехода. `trash-note` остаётся отдельной операцией перемещения выбранной заметки в корзину. `restore-note` возвращает ту же заметку с тем же ID и исходным Markdown. Существующая проверка несохранённого черновика, подтверждения в Calendar и Undo задач не переписывались. Модели, схема и ключи хранилища не менялись.

Глобальные стили ссылок не затронуты. Настоящий content anchor сохраняет подчёркивание; URL/Markdown заметки остаются исходным текстом. Приложение не превращалось в новый renderer заметок.
