# Path Mobile на Windows через копирование текста

Этот способ предназначен для интерфейса, где можно открыть текстовые файлы среды, но нельзя скачать ZIP. Понадобится возможность скопировать **полное содержимое** файла. Удалённое скачивание или доступность Copy в конкретном клиенте не считаются подтверждёнными.

Восстанавливается готовый мобильный web preview версии `d8763ec28690c956c4b2abcc8189c051f26688b6`, включая исправленную позицию и иконку Habits. Подготовленный ZIP — 149555 байт, SHA-256:

```text
6863bf415ab2a53db263e6bf47844641e1134f3d006457e78eb333dad51819ea
```

## Один файл

1. В панели «Файлы» открой `docs/mobile/windows-preview/Restore-PathMobile-Windows.txt`.
2. Нажми внутри текста, затем Ctrl+A и Ctrl+C, чтобы скопировать весь файл. Это примерно 200 КБ. Последняя строка файла — `'@`.
3. На своём Windows-компьютере открой обычный PowerShell или Терминал с PowerShell.
4. Вставь текст целиком и нажми Enter. Текст представляет собой обычные видимые команды PowerShell и ZIP, записанный в Base64; это не encoded PowerShell command.
5. После сообщения `PATH MOBILE READY` окно уже будет находиться в папке приложения. Сохрани выведенный путь для следующих запусков.
6. Выполни:

```powershell
py -3 -m http.server 8010 --bind 127.0.0.1
```

7. Открой в Chrome/Edge `http://127.0.0.1:8010`. Окно сервера оставь открытым. Ctrl+C останавливает его.
8. Для мобильной компоновки: F12 → Ctrl+Shift+M → Responsive → 390×844. Также доступны 320 и 430 px.

Если `py -3 --version` не показывает установленный Python 3, сначала установи Python с официального python.org. Если `python --version` показывает Python 3, команду сервера можно начать с `python` вместо `py -3`.

## Если большой файл не отображается целиком

Есть пять файлов меньше 50 КБ каждый. Последовательно открой, скопируй целиком и выполни **в одном и том же окне PowerShell**:

```text
01-PathMobile-part.txt
02-PathMobile-part.txt
03-PathMobile-part.txt
04-PathMobile-part.txt
05-PathMobile-part.txt
```

Части 01–04 только собирают текст в переменной текущего сеанса. Часть 05 проверяет полный архив и распаковывает приложение. После `PATH MOBILE READY` выполни ту же команду сервера выше. При неполном копировании или неверном порядке проверка не должна допустить распаковку несовпадающего ZIP; начни копирование частей снова с 01.

## Что выполняет восстановление

- Декодирует ZIP в памяти и проверяет SHA-256 **до записи файлов**.
- Создаёт отдельную папку `%USERPROFILE%\PathMobile-Test-d8763ec`. Если такая уже есть, выбирает другое имя с суффиксом.
- Сохраняет ZIP и распаковывает его в эту новую папку; переходит в её `Path-Mobile`.
- Выводит точную команду запуска локального сервера.

Команды не обращаются к сети, не устанавливают программы, не меняют execution policy, не удаляют файлы и не перезаписывают существующую папку. Рабочая desktop-копия Path, настройки, аккаунты и пользовательские данные не используются. PowerShell можно запускать без администратора. Сам сервер запускается отдельной командой пользователя и привязан к 127.0.0.1.

Первые команды можно прочитать над большим блоком Base64. Они выполняются только после получения полного аргумента. Если PowerShell ожидает продолжение ввода и показывает `>>`, возможно, скопирован не весь файл; Ctrl+C прерывает незавершённый ввод.

## Проверка и ограничения

Python и независимо Node восстановили из текста точно те же байты ZIP; CRC ZIP и все распакованные файлы совпали с исходным готовым preview. Обе формы — цельный файл и пять частей — проверены на совпадение payload. Исходный ZIP ранее проверен браузером Chromium/Linux: загрузка, задача с сохранением/reload и исправленная навигация Habits.

PowerShell и Windows в этой среде не доступны, поэтому полный Windows-запуск этих команд здесь **не проверен**. [verification.json](verification.json) разделяет проверки байтов и непроверенный native runtime. Скопированность файла в конкретном интерфейсе и получение его пользователем также не считаются проверенными.

Изменены только документы передачи. Код приложения, desktop, GitHub, Paperclip, Daytona, production и конфигурация среды не изменены; никакой публикации или push.
