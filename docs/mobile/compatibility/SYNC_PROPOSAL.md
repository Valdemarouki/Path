# Предложения будущего sync — не реализованы

Ничего из этого документа не является текущим API/полем desktop. Аккаунты, remote transport и production не подключены. Текущая надпись — локальное сохранение, никогда Synced.

| Область | Предлагаемый контракт | Необходимая проверка перед реализацией |
|---|---|---|
| Offline | IndexedDB для документов/вложений и транзакционного outbox; shell/service worker версионировать отдельно. Операцию записывать вместе с локальным изменением, до UI-успеха | Отказ квоты/закрытие браузера посреди транзакции; совместимость с текущим localStorage; не обещать offline shell до её реализации |
| Повторная отправка | Стабильный operationId + entityId + workspaceId + baseRevision; сервер хранит результат по idempotency key | Повтор/перестановка/частичная доставка не создают дубликаты; аудит коротких desktop-ID и namespace до переноса |
| Удаление/Undo | Tombstone с версией и сроком хранения; восстановление отдельной операцией с тем же ID | Порядок delete/restore, ссылки и удаления вложений; текущий in-memory task Undo не считать sync-контрактом |
| Конфликты | Optimistic concurrency по baseRevision; независимые поля можно сливать только с сохранением общей базы; текст/время/ссылки требуют явного выбора пользователя | Два устройства, редактирование одновременно с delete, завершение связанной тренировки/задачи; нельзя незаметно last-write-wins для всего документа |
| Повторения | Согласованный seriesId/occurrenceDate/scope; изменения серии и исключений атомарны, occurrence IDs стабильны | one/following/series, отменённые даты, перенос DST, исключения после изменений серии |
| Вложения | Контент-адресуемый blob ID + manifest/reference; загрузка/повтор/очистка отдельно от документа | Отмена/обрыв, orphan cleanup, права доступа, mime/size, отсутствие потери unsupported блоков Notes/Canvas |
| Personal / Shared | Явный workspace/owner и серверные membership/ACL; локальный флаг не даёт права доступа | Запрет операций после удаления участника, доступ к вложениям/истории, отсутствие утечки между workspace |
| Миграции | schema/entity version + capabilities клиента; резервный экспорт/проверенная миграция; старый клиент не пишет неподдерживаемые сущности | Round-trip всех неизвестных полей, отказ новой версии/частичного update; сквозные fixture-тесты desktop↔mobile до реального sync |
| Logout | Показать число неотправленных операций; сохранить изолированный draft или экспорт/явное удаление. Не стирать outbox молча | Выход/смена аккаунта offline, доступ следующего пользователя к сохранённым данным, отзыв ключей/permissions |
| Настройки | Account/workspace preferences отдельно от device settings, UI navigation, notification permission и reduced motion | Устройство не меняет чужую схему отображения/локальные OS-разрешения; эффективный reduced motion всегда учитывает ОС |

Порядок работ: golden fixtures/round-trip contract → локальный адаптер и outbox → имитатор транспорта/серверных конфликтов → ревью прав/миграций → только затем авторизованный тестовый backend. Полноценный desktop importer, общая библиотека моделей и реальный transport не входят в этот этап.
