# Path Mobile — Calendar completion

Рабочая копия `/workspace/Path`, локальная ветка `feature/path-mobile-alpha`. Исходный HEAD: `6f5ef645c45975847818063264d509db3b45d846`, перед началом рабочая копия чистая. Исследование desktop проведено только чтением исходников; [аудит](AUDIT.md) содержит конкретные функции, конфигурации и порядок загрузки.

## Что перенесено

`calendar-pulse.js:startCalendarHold` и `calendar-pulse.css` задают удержание 800 мс и линейное заполнение контура SVG: `pathLength=100`, `stroke-dashoffset:100→0`. В desktop последний загруженный `path-pulse-360.js` переопределяет ранний эффект. Поэтому источником импульса выбрана актуальная Path Pulse v6.1, а не старая анимация 520 мс / 320 px.

У актуального desktop Calendar импульс сдвигает соседние карточки. По требованию мобильного этапа это движение заменено отдельным визуальным слоем. Контурное кольцо взято из **существующего `todayWave` той же Path Pulse**, его затухание и отклик соседних поверхностей настроены по Calendar v6.1. Это явная адаптация существующей системы, а не утверждение, что desktop Calendar уже рисует такое кольцо.

`motion-master.js:check` задаёт рисунок галочки, включая реальные промежуточные масштабы и небольшой поворот. На телефоне поворачивается только появляющаяся галочка; карточка, её текст, соседи и навигация неподвижны.

| Параметр | Фактическая реализация |
|---|---|
| Удержание | 800 мс; длительность desktop сохранена |
| Контур | SVG по реальным размерам и радиусу карточки; 1,5 px; линейное заполнение |
| Отмена | Обратное заполнение и затухание за 180 мс; без записи и волны |
| Движение пальца | Отмена от 7 CSS px — порог взят из desktop drag |
| Короткое касание | До 200 мс открывает редактор; 201–799 мс — отмена удержания без открытия редактора; мобильное различение tap/hold |
| Галочка | 565 мс; scale .28 / 1.32 / .89 / 1.055 / 1; offsets 0 / .35 / .67 / .85 / 1; rotate −9 / 2 / −1 / .5 / 0° |
| Волна | Радиус 560 CSS px, диаметр 1120 px; расширение/затухание 1060 мс; cubic-bezier(.16,.6,.3,1) |
| Кольцо Path | Scale .025 / .13 / .62 / 1; opacity 0 / .65 / .25 / 0; offsets 0 / .12 / .55 / 1 |
| Отклик поверхностей | Центральный 850 мс, соседний блик 1010 мс; задержка по расстоянию до 410 мс; сила 125%, attenuation exponent .9 |

На touch не перенесены desktop `preventDefault` и pointer capture для перетаскивания. `touch-action:pan-y pinch-zoom` оставляет нативную вертикальную прокрутку. Отмена происходит при движении, прокрутке, pointercancel, втором касании, потере фокуса окном, уходе в фон и смене даты/раздела. Системная подсветка и выделение текста отключены только на карточках, ведущих себя как кнопки; поля редактора и доступный keyboard focus сохранены.

## Сохранение и доступность

Меняется только `event.done`; постоянный ID, даты/время, тип, важность, описание и неизвестные поля сохраняются. Модель и версия хранилища не менялись. Существующие ограничения на связанные события, повторения, тренировки с привязками, Free Time и дедлайны сохранены.

Единственная операция запускается на пороге удержания под существующим Web Lock. Перед отложенной записью заново проверяется актуальность жеста/даты/экрана. Фидбэк появляется после успешного `localStorage.setItem`, независимо от будущей синхронизации. Ошибка не меняет состояние; сообщение предлагает повтор. Конфликт требует явного обновления и проверки данных перед повтором. Повторные касания во время записи не создают дополнительных операций или редакторов.

Карточка обновляется на месте. Место для статуса зарезервировано заранее: не меняются размеры карточек и scroll position. У завершённой карточки остаются галочка, название, время, тип и важность. Кнопка «Отменить выполнение» доступна в сообщении; позднее выполнение можно отменить существующим checkbox в редакторе. Enter/Space открывают редактор, Shift+Enter завершает доступное событие. Статус, время и важность входят в доступное описание карточки; результаты объявляются через live region. Скрытое сообщение исключается из фокуса при раскрытии навигации или открытии редактора.

Все анимации конечны. В состоянии покоя нет нового animation loop. Волна и блики — pointer-events:none слой, обрезанный границами видимой области расписания и верхом нижней панели. Он удаляется после окончания, прокрутки или смены контекста. Прозрачная панель, её материал/анимации и графитовые поверхности не перерабатывались.

## Воспроизводимая проверка

Тесты используют новые браузерные профили, синтетические события и только localhost. Весь внешний трафик браузерных сценариев заблокирован. Существующие пользовательские хранилища не открывались.

```bash
cd /workspace/Path
python3 mobile/build.py
python3 mobile/typography-preview/build.py
# В отдельных терминалах:
python3 -m http.server 8010 --bind 127.0.0.1 --directory mobile/dist
python3 -m http.server 8020 --bind 127.0.0.1 --directory mobile/typography-preview/dist
# При работающих серверах:
node mobile/tests/run-polish.cjs --evidence /tmp/path-completion-release --with-typography
```

Финальный прогон: **16/16 наборов прошли**, включая **68 проверок моделей** и **31 сценарий завершения Calendar**. Статическая сборка основного приложения и отдельного typography preview успешна. Пройдены короткое касание, успешное удержание, раннее отпускание, нативная прокрутка, быстрые повторы, ошибки завершения/отмены и повтор, stale conflict, отмена ожидающей записи при смене даты/экрана/фона/прокрутке, перезагрузка, края экрана, альтернативы клавиатуры/редактора. Матрица: **320/390/430 × EN/RU/ES × обычная/reduced motion**; отдельно проверена настройка Path Motion Off.

Результаты: `regression-summary.json`, `completion-verification.json`, `test-results.txt`. Дополнительно проверены отсутствие горизонтального переполнения, неизменность геометрии карточек и nav, удаление transient layers, отсутствие работающих анимаций в покое и accessibility tree завершённой карточки. Уход в фон и blur проверяются симуляцией lifecycle-событий; вертикальная прокрутка и удержание — настоящими Chromium touch events через CDP.

В ней: короткое касание → редактор; преждевременное отпускание → возврат контура; удержание → сохранение → волна и галочка; отмена выполнения; повторное завершение и перезагрузка. `calendar-completion.gif` — уменьшенное превью того же видео.
