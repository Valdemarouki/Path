# Path Sport — Desktop & Mobile, SPORT A1

11 ноября 2026. Реализована цепочка в существующем приложении: каталог →
программа/шаблон → общий Calendar → фактические подходы → выход/возобновление →
частичная или полная сохранённая история. Нового приложения, хранилища, backend
или синхронизации с пользовательской установкой не создавалось.

## Что работает

- **Каталог:** 144 настоящих SVG, локальные названия EN/RU/ES, поиск, All,
  Favorites, Recent, пользовательские определения, оборудование и категории,
  подробности и нейтральные placeholders. Повторный случайный Add не дублирует
  позицию; отдельный Duplicate создаёт новый slot ID.
- **Мышцы:** утверждённые Front/Back, плавная голова, доступный текстовый список
  всех 19 групп, пресеты Upper/Lower/Core/Push/Pull/Full. Мышцы сочетаются через
  OR, остальные фильтры дополнительно сужают выдачу. Ручное исключение Biceps
  сохраняется при включении пересекающегося Pull. «Хочу тренировать» не меняет
  «В тренировке».
- **Редактор:** программы и именованные A/B/C, создание, переименование,
  дублирование, архив/восстановление; подходы, типизированная цель, отдых,
  примечания, порядок ручкой и доступными кнопками. Именованный пустой шаблон
  можно сохранить, но нельзя запланировать или начать.
- **Различия платформ:** desktop добавляет сразу, оставляет библиотеку открытой
  и использует существующий Undo/Redo. Library/Schedule делят одну контекстную
  область. Mobile выбирает временный упорядоченный набор; Add N сохраняет его
  один раз, Cancel не меняет тренировку. Другой навигации из референсов нет.
- **Calendar:** одно общее событие со ссылкой на шаблон и независимым плановым
  снимком. Перенос сохраняет event ID и снимок. Открытие программы/расписания не
  создаёт событий; открытие запланированной тренировки возобновляет ту же сессию.
- **Выполнение:** отдельные фактические поля повторов/веса/секунд/метров,
  переходы между упражнениями, сопоставимый прошлый результат, логирование,
  отмена подхода, отдых, pause/resume/skip/+time. Сессия одна; повторный клик не
  создаёт второй подход или историю. Сырые незавершённые значения сохраняются
  отдельно от фактов, в том числе при выходе и перезагрузке.
- **Таймеры:** timestamps, сохранённые паузы и пересчёт при возвращении;
  активный JavaScript в фоне телефона для правильного расчёта не нужен.
- **История:** новые записи содержат только реально отмеченные подходы,
  plannedSetCount и partial/complete. Пустой финиш результата не создаёт.
  Снимок названия, варианта, единиц и условий не меняется от будущих правок.
  Несопоставимые условия не объявляются рекордом.
- **Ошибки:** локальный успех только после записи; quota/конфликт не заменяет
  прежние данные, сохраняет форму и даёт повторить. Конфликт двух вкладок
  обрабатывается действующей транзакционной границей.

## Повторное использование и данные

Desktop использует действующие владельцы `sport*.js`, `workout-builder.js`,
PathRepository и Undo. Mobile использует существующие repository/Web Locks,
numeric pickers, Calendar, event editor, Motion и локализацию. Нижняя прозрачная
панель PHONE R3, её материал и жесты не переделывались. Общая чистая логика
находится в существующей папке `domain/`, без DOM/диска/сети; сохранение остаётся
в платформенных транзакциях. Таблица исходного аудита и контракт, написанный до
изменения модели: [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

Используются прежние `programs`, `workouts`, `events`, `activeWorkout`,
`workoutRecords`; опциональный `sportsLibrary` хранит только предпочтения и
пользовательские определения. Каталог не копируется в каждую базу. Новые
определения имеют `catalog:<id>`, позиции — свои независимые ID. Старые ID не
сопоставляются с картинками по названию.

Новые сессии/результаты отмечены `sportVersion:4`; `actual` содержит отдельные
значения. У `weightReps` primary unit остаётся `reps`, вес — `actual.weightKg`.
Старое `kg` остаётся только весом, повторения из цели не придумываются.
Неизвестные поля, старые snapshots/history, программы и определения сохраняются.
Неподдержанные блоки/единицы показываются read-only; массовой разрушающей
миграции нет. Повреждённое обязательное состояние не переписывается.

В desktop-test команда применяется к полному canonical checkpoint, отдельно
от проекции UI. Проверены неизвестные поля, envelope/image pool, Undo и экспорт
настоящим **обновлённым desktop-валидатором**. В тестовом режиме не читается и
не записывается ключ native mobile. Совместимость относится к обновлённой desktop
версии этого пакета: старый установленный релиз может не понимать новые типы.
Автоматического обмена данными между компьютером и телефоном нет.

## Материалы и разрешённые расхождения

Пакет распакован отдельно; prompt, исходное ТЗ, аудит и acceptance прочитаны.
Главный prompt имеет приоритет над противоречащими деталями референсов:
шаблоны A/B/C — не дни недели; нижний Overview из PNG не стал постоянной частью
редактора; чужая навигация, демонстрационные значения, CDN/widget state не
переносились. Реальные SVG содержат лицо/волосы и внутренние вырезы: их проверенные
compound paths сохранены, а не объявлены заново нарисованными «без лиц».

Аудит: **20/20** внешних хешей; архив **192 файла**, **144 SVG / 12 категорий**,
все пути существуют, размер SVG вместе **2 791 504 байта**, viewBox 512×512,
нет scripts/images/foreignObject/обработчиков/внешних ссылок. Все runtime SVG
побайтно совпадают с исходниками. Девять репрезентативных SVG дополнительно
отрендерены и просмотрены. Полные результаты:
[ASSET_AUDIT.md](ASSET_AUDIT.md), [RUNTIME_CHECKS.json](assets-audit/RUNTIME_CHECKS.json).

Scapular pull-up отсутствует в архиве — отдельное определение с честным
placeholder. Карта покрывает 15 из 19 групп; adductors/hipflexors/hiprotators/neck
сохранены как текстовые фильтры (19 затронутых записей). Типы и ES явно добавлены,
secondary muscles не выдумывались. Это не медицинская сертификация. У поставленных
иллюстраций нет отдельного файла лицензии; происхождение и отсутствие заявления
о дополнительных правах сохранены в `assets/sport/PROVENANCE.md`. Локальный
Manrope сопровождается существующей OFL; внешнего font CDN для Sport не нужно.
Исходные PNG, архивы и контактные листы не включены в runtime.

к Linux Chromium 156.0.8078.79, а не к настоящему Safari/установленному Windows.
Зависимости не устанавливались; browser request interception читает локальные
сборки и блокирует внешние адреса, не запускает серверы.

Browser-проверки включают Cancel/Add N, порядок/дубли/IDs, raw drafts/reload,
общий Calendar и retime, частичный finish, immutable history, повторные клики,
искусственную ошибку записи на каждом шаге и Retry, конфликт вкладок,
фактические вес/повторы и дробные секунды. Модель проверяет старые копии,
неизвестные поля, legacy kg, полночь, паузы и сохранение provenance.

Матрица: mobile 320/360/390/430, EN/RU/ES, оба режима; landscape 844×390;
desktop 1366×768 и 1920×1080, EN/RU/ES, 125% текст, клавиатура и reduced motion.
Есть отсутствие SVG, доступные кнопки минимум 44 px и сенсорный reorder/pan.
Изменения высоты visualViewport моделируют клавиатуру, не доказывая физическую.
Старые DOM-тесты получили только актуальный typed draft assertion и jsdom
CSS.escape shim; проверки результата/сохранения не отключались.

Финальный review дополнительно исправил сохранение старых пустых шаблонов без
`exercises`, противоречивые target/targetValues при явном применении progression,
локализованный anchor мини-календаря и перенос несохранённого raw input/Retry
между test-копиями с одинаковыми IDs. Переключение копии теперь сначала сохраняет
черновик; при ошибке остаётся в исходной копии с прежней формой. Команда дополнительно
привязана к dataset/session. Отдельный browser regression доказывает сохранность
обеих копий, отсутствие native-key обращений и валидный canonical export.

В browser acceptance нет открытых провалов. В тесте исходного HTML-концепта
воспроизведён его известный провал исключений (5/6); runtime исправлен и PASS.
Десять старых необязательных Google Fonts запросов остальной desktop-оболочки
заблокированы; локальные Sport-шрифты отрендерены, page errors отсутствуют.

## Локальная поставка и оставшиеся проверки

Инструкция: [LOCAL_TEST_RU.md](LOCAL_TEST_RU.md). Готовый ZIP содержит отдельные
`Path-Desktop`, `Path-Mobile`, helper, локальные assets/fonts, BUILD.txt и runtime
hashes. Нужен существующий Python 3.10+; Node/npm для готового запуска не нужны.
На вашем iPhone можно обновить папку Path-Mobile, сохранив существующие
Tools/Trust/закрытые сертификаты и тот же HTTPS origin; сеть автоматически не
открывается. При изменении IP нужна сверка текущей настройки.

`export.py` создаёт полный source tar.gz текущего коммита (desktop + mobile +
domain + assets + документация), Git bundle feature-ветки, готовый ZIP и
SHA256SUMS. Проверяется ZIP CRC/каждый member, затем независимо восстанавливаются
исходники/история и проверяется готовая сборка; фактический результат находится
в `DELIVERY.json`. Исходники сборки не подменены одним mobile/dist.

На настоящем iPhone 12 Pro / Safari iOS 26.6.1 остаётся проверить клавиатуру,
safe areas, жесты, нагрузку, приостановку и возврат; установленная Windows-версия
не запускалась. PWA, фоновые звуки, холодный offline и облачная синхронизация не
заявляются. Для повторного открытия нужен доступный локальный сервер.

Коммит, bundle и архивы сейчас находятся в этой среде. Файлы можно передать
вложениями/ссылками чата; доступность скачивания зависит от клиента. Внешняя
резервная копия появится после вашего скачивания и сохранения вне среды —
локальный коммит сам по себе этого не обеспечивает. После поставки этап
останавливается для вашего тестирования и решения.
